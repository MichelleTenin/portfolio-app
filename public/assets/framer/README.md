# Framer asset archive

Local copies of the authored imagery from the home, Aurora, Tecan, and About
pages at `michelletenin.space`.

The original Framer asset IDs are preserved as filenames. Framer sometimes
serves AVIF or WebP content from a URL ending in `.png` or `.jpg`; local files
use their actual formats.

Reference assets through `src/data/framer-assets.ts`.
